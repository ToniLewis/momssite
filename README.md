# GloFro Hair LLC — Static Website Project

A static e-commerce website project created for **GloFro Hair LLC**, a hair business I co-owned. The project was originally developed to support the business’s online presence and provide customers with a product-focused shopping experience.

This repository preserves the front-end HTML portion of the website as a portfolio project. It demonstrates my experience creating a business-oriented storefront layout, organizing e-commerce content, and building a branded web page with HTML.

> **Note:** The original Shopify store is currently down, and this project is not hosted online. Some images may not appear because the original image files were saved locally on the development computer and have not been uploaded to this repository.

## ✨ Features

- Static storefront layout for a hair business
- Product-focused shopping page
- Business branding and visual presentation
- Navigation elements for a customer-friendly experience
- Product information and promotional content
- Calls to action for potential customers
- HTML structure preserved as a web-development portfolio project

## 🛠️ Built With

- **HTML5** — Website structure, product sections, navigation, and content layout
- **CSS3** — Styling and design elements included within the project, where applicable
- **Local image assets** — Original hair-product and business-branding images used during development

## 🚀 Getting Started

To view the project locally, follow these steps:

1. Clone the repository:

```bash
git clone https://github.com/ToniLewis/momssite.git
```

2. Move into the project folder:

```bash
cd momssite
```

3. Open `shop.html` in your preferred web browser.

For a local development preview, open the project folder in **Visual Studio Code** and use the **Live Server** extension.

## ⚠️ Current Project Status

This is an archived static HTML project and is not currently deployed or hosted online.

The original GloFro Hair LLC Shopify store is no longer active. In addition, some images may not load when viewing the project because they were stored locally and were not included in the GitHub repository.

Although some visual assets are unavailable, the HTML file preserves the underlying structure and core layout of the business website.
